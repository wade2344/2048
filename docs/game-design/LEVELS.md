# 六个系统节点 LEVELS

> 文档版次：0.1.0-docs.1 · 2026-11-25 · Phase 0 文档交付；游戏尚未实现。
> 来源：[输入基准](../reference/SOURCE-BASELINE.md)；对应章节 / 说明：4。
> 效力：仅 PRD 明列项为用户已确认；其余沿用设计基准。本文新增接口细化、测试设计、任务拆分属于交付建议；所有初始数值待模拟与试玩验证。
> 待决议建议没有生效；受影响规则落地前须关闭对应 [D 项](../development/OPEN-DECISIONS.md)（验证型门按登记说明执行）。

以下是最后一版设计中的目标，不采用更早的 800/1000 分、50 步、128 方块等草案。

| 节点 | 名称 | 固定目标 | 词缀范围 | 奖励 |
|---|---|---|---|---|
| 01 | 核心启动 | 生成/合成至少一个 32 能量单元 | 无 | 第 1 次三选一 |
| 02 | 能量聚合 | 生成/合成至少一个 64 | 增益型 1 个 | 第 2 次三选一 |
| 03 | 过载运算 | 本关累计 300 分 | 增益、限制、双刃剑 1 个 | 第 3 次三选一 |
| 04 | 稳定性测试 | 完成 40 次有效移动 | 限制、双刃剑 1 个 | 第 4 次三选一 |
| 05 | 极限超频 | 生成/合成至少一个 256 | 限制、双刃剑 1 个 | 第 5 次三选一 |
| 06 | 终极协议 | ZERO HP 降至 0 | 无，Boss 专属规则 | 冒险结算 |

关卡 1 为教学，2 介绍环境，3–5 逐步强化策略；Boss 应为最终综合挑战。每关最多一个词缀；不默认引入步数上限。生存关卡的 40 步为达成条件，而非必须在 40 步内完成另一目标。

## 跨关与目标验收

| 领域 | 新关重置 | 整轮保留 |
|---|---|---|
| 棋盘、分数、有效步、EP | 新棋盘与本关基准，再应用已持有技能/本关词缀 | 冒险统计保留，统计口径见 D19 |
| 计数器 | 关卡计数、垃圾回收触发标志 | 紧急重启整轮使用状态；回滚例外见 D10 |
| 技能 | 不清除已获得模块 | 第 1–5 关各选 1，进入第 6 关持有 5 个 |
| 词缀 | 本关有效词缀更新 | 已出现词缀用于避免重复；空池回退见 D06 |
| 回滚 | 旧关快照失效 | 操作日志追加保留 |

数字目标检查至少达到阈值，不要求恰好等于目标；定向超频达到数字目标也可以通关。分数目标只读取本关累计分数；生存目标按有效 MOVE 计数，技能和无效滑动不增加进度。初始化即达标与判胜时点仍为 D02。

每个节点均测试目标前一单位、恰好达标、超额达标及一次性完成事件；Boss 则依据 HP。准备页显示来自同一配置的目标、词缀与有效 EP 规则，不能另存一份 UI 数值。
