# 十二环境词缀 PROTOCOLS

> 文档版次：0.1.0-docs.1 · 2026-11-25 · Phase 0 文档交付；游戏尚未实现。
> 来源：[输入基准](../reference/SOURCE-BASELINE.md)；对应章节 / 说明：6。
> 效力：仅 PRD 明列项为用户已确认；其余沿用设计基准。本文新增接口细化、测试设计、任务拆分属于交付建议；所有初始数值待模拟与试玩验证。
> 待决议建议没有生效；受影响规则落地前须关闭对应 [D 项](../development/OPEN-DECISIONS.md)（验证型门按登记说明执行）。

### 6.1 增益型

| 建议 ID / 名称 | 效果 |
|---|---|
| energy-surge / 能量富集 | 本关初始 EP 由 4 提升至 8 |
| capacity-boost / 扩容协议 | 本关 EP 上限从 10 提升至 15 |
| advanced-cache / 高级缓存 | 初始化额外生成一个 16 方块 |
| turbo-mode / 运算加速 | 正常合并分数增加 25% |

### 6.2 限制型

| 建议 ID / 名称 | 效果 |
|---|---|
| low-power / 低功耗模式 | EP 上限降至 6 |
| command-tax / 指令税 | 所有主动技能有效消耗 +1 EP |
| data-corruption / 数据污染 | 初始化一个固定不可移动障碍 |
| periodic-error / 周期性故障 | 每 5 次有效移动损失 1 EP，最低为 0 |

### 6.3 双刃剑型

| 建议 ID / 名称 | 增益 | 代价 |
|---|---|---|
| extreme-overload / 极限超载 | 每对普通合并获得 2 EP | 所有主动技能消耗 +2 EP |
| fast-spawn / 高速生成 | 每次有效滑动的正常生成固定为 4 | 每 4 次有效滑动额外生成一个 2，无空位则跳过 |
| unstable-matrix / 不稳定矩阵 | 初始额外生成两个 16 | 每 10 次有效移动随机重排普通方块 |
| energy-compression / 能量压缩 | 主动技能有效消耗 −1 EP，最低 1 | EP 上限降至 6 |

### 6.4 抽取与兼容性

按第 4 节关卡类别白名单筛选；第一、六关没有词缀。尽量不在同轮重复；当技能有效消耗超过候选词缀下的最大 EP 时排除该候选；排除对目标没有实际作用的词缀（原讨论示例：纯生存关不抽纯分数增益）。候选及最终结果写入状态，刷新不得重抽。

词缀应在关卡准备界面完整展示，并实时展示实际 EP 上限、技能消耗、合并收益等。周期性机制应显示下一次触发所需的有效移动数（建议）。技能与词缀通过同一规则修饰器和同步事件机制结算；优先级、覆盖语义、舍入、候选池为空的回退方案见第 15 节，需固化为测试。

## 兼容筛选规格边界

候选输入至少包含关卡类别、目标、已获得技能及历史词缀。基准要求先遵守关卡类别白名单、技能可支付性与目标相关性；「尽量不重复」不是无条件硬禁重复。回退规则没有获准前，不允许自创重抽次数或把空池视为崩溃。

本包沿用 12 个建议 ID：4 增益、4 限制、4 双刃剑。词缀每关最多一个，不应为了测试首版而让两种互斥词缀同时生效。跨词缀叠加仅能作为未来方案讨论，不能改变本版。

| 冲突 / 边界 | 当前效力 | 所属决议 |
|---|---|---|
| 高速生成固定 4 与高阶生成 30% | 两条效果均保留；固定值优先只是建议 | D06 |
| 低功耗/压缩导致持有技能费用超上限 | 基准要求排除不兼容候选；具体算法验收后冻结 | D06、D17 |
| 周期性效果与通关同一步 | 胜利优先；完整阶段顺序未定 | D02、D03 |
| 不稳定矩阵与矩阵重构 | 普通方块重排的空位/锁定/不变结果策略 | D07 |
| 百分比计分与并行分数加成 | 基础分来源确定；倍率叠加/舍入时点未定 | D03、D05 |
| 历史去重后候选为空 | 不放宽安全兼容；其余回退仍为建议 | D06 |

周期计数只接受有效 MOVE，不接受技能、无效滑动或现实时间。高速生成的额外 2 无空位跳过已是基准；其余初始化或事件空位耗尽行为不要据此推断，见 D01/D07。

逐词缀边界用例为 PT-01 至 PT-12，详见 [测试用例](../development/TEST-CASES.md)。
