> 文档版次：0.1.0-docs.1 · 2026-11-25 · Phase 0 文档交付；游戏尚未实现。
> 来源：[输入基准](../reference/SOURCE-BASELINE.md)；对应章节 / 说明：2。
> 效力：仅 PRD 明列项为用户已确认；其余沿用设计基准。本文新增接口细化、测试设计、任务拆分属于交付建议；所有初始数值待模拟与试玩验证。
> 待决议建议没有生效；受影响规则落地前须关闭对应 [D 项](../development/OPEN-DECISIONS.md)（验证型门按登记说明执行）。

玩家是刚启动的 AI 核心，在数字世界中通过能量聚合突破系统节点，安装功能模块，最终突破中央控制协议 ZERO。失败称为核心崩溃，重新开始称系统重启。剧情文本克制，不打断操作。

| 游戏术语 | 世界观术语 |
|---|---|
| 数字方块 / 合并 | 能量单元 / 能量聚合 |
| 棋盘 | 运算矩阵 |
| 关卡 | 系统节点（NODE） |
| 主动技能 | 功能指令（Active Modules） |
| 被动技能 | 强化模块（Passive Modules） |
| 通关三选一 | 系统升级 / 安装模块 |
| 词缀 | 系统环境协议（System Protocol） |
| 障碍 | 数据污染 |
| Boss | 中央控制协议 ZERO |

冒险循环：开始冒险 → 关卡准备（显示目标、词缀、已有模块和实际 EP 规则）→ 初始化独立棋盘 → 移动/合并/释放技能 → 达成目标 → 奖励三选一 → 进入下一关；第六关胜利后直接结算。失败结束本轮冒险。每轮从零技能开始，不设置局外成长。

每关重新初始化棋盘与关卡分数、有效移动数、EP、关卡计数器及关卡限定触发器；继承已获得的技能、冒险累计统计、整轮仅一次的紧急重启使用状态。技能和词缀改变规则，但不应破坏经典 2048 的可读性。

## 体验闭环与状态闭环

玩家在准备页理解本关目标和实际规则，在棋盘中通过合并获取资源，主动技能提供操作选择，被动模块改变构筑收益。通关奖励提供下一关的新策略；每关新棋盘限制前关局面滚雪球，但技能持续继承。失败结束本轮，不保留永久成长。

玩法中的「系统升级」只指通关选模块，不表示关卡内等级或经验值。「核心崩溃」是败局文案，不表示玩家生命值系统。「无限进化」项目名不意味着首版无限关卡。
