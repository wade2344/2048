### 8.1 设计系统

风格：深空、几何线条、克制发光、蓝紫色能量、数字高可读性。世界观作为视觉包装，技能必须同时呈现直白效果和科技命名。Boss 采用红色几何 AI 核心、旋转轨道和故障动画，不需复杂角色美术。使用 CSS Variables 主题 Token。

| Token | 色值 | 用途 |
|---|---|---|
| background | #080C16 | 深空背景 |
| surface | #141C2E | 容器 |
| grid | #26334A | 棋盘网格 |
| primary | #38BDF8 | 科技蓝 |
| accent | #8B5CF6 | 能量紫 |
| energy | #22D3EE | EP、激活 |
| success | #34D399 | 通关 |
| warning | #FBBF24 | 预告 |
| danger | #F43F5E | 故障/Boss |

数字色阶：2 #273449；4 #354A62；8 #155E75；16 #0369A1；32 #1D4ED8；64 #4338CA；128 #6D28D9；256 #9333EA；512 #C026D3；1024 #DB2777；2048 #B45309；4096 #0E7490。高阶方块可有轻量动态边框或能量脉冲。文字保持足够对比度，不仅以颜色表达障碍、选中、锁定或禁用。

### 8.2 页面与主要状态

| 页面 | 信息与交互 |
|---|---|
| 首页 | 2048 INFINITE 标识，启动核心、继续演化（有有效存档时）、系统设置；历史记录非首版必需 |
| 节点进度 / 准备 | 6 节点状态、当前固定目标、词缀及双刃剑影响、已安装模块、进入节点 |
| 游戏主界面 | 节点名称、目标进度、本关分数/步数、EP 段条与实际数值、4×4 棋盘、主动模块及有效消耗、被动模块、暂停 |
| 奖励界面 | 节点突破、关卡统计、三个互斥可选技能、完整效果与确认安装；不能刷新候选 |
| 冒险结算 | 胜败、通过节点、累计分数、最大方块、有效移动、耗时、最终模块、重新开始、回放/导出入口 |
| 回放（辅助页） | Seed、规则版本、节点、步号、棋盘、分数/EP、事件详情、首末步、前后步、进度拖动、自动播放/倍速、关卡跳转 |

原讨论五个核心页面不包含后加入的回放辅助页；无需增加第六个核心玩法阶段。Boss 在游戏主界面增设 HP 条、红色预告、目标格、封锁倒计时；低 EP 技能显示禁用状态。指令交互：清除/超频选一个目标，交换选两个；无目标技能直接执行或确认；取消不消耗，选择期间禁滑动。

### 8.3 动效与输入

| 反馈 | 建议时长 |
|---|---:|
| 方块移动 | 100–140 ms |
| 普通合并 | 150–180 ms |
| 新方块 | 120 ms |
| 高阶合并 | 200 ms |
| 技能释放 | 200–400 ms |
| 关卡完成 | 600 ms |
| Boss 攻击 | 300 ms |

优先 CSS transform/opacity 和 Web Animations API。游戏逻辑先提交，UI 根据事件播放。首版动画期间短暂锁定输入，最多缓存一次后续滑动；关卡切换/奖励/终局清除缓存。支持触屏四向手势、键盘方向键、合理阻止棋盘触控导致页面滚动、安全区域和 prefers-reduced-motion。音效与设置可做轻量支持，不应阻塞主流程。

## 交互验收补充（交付建议）

| 场景 | 可验证要求 |
|---|---|
| 取消目标选择 | 回到操作状态，棋盘/EP/日志无变更；只由最终确认发出 USE_SKILL |
| 动画期间输入 | 最多缓存一次，关卡/奖励/终态清缓存；不能用动画完成回调决定胜负 |
| 保存失败 | 显示未保存状态及可恢复提示，不能误报已保存；策略待 D12 |
| 回放 | 明示只读与版本，离开回放后正式冒险状态/存档不变 |
| 辅助可访问性 | 锁定、障碍、禁用都有文字/形状提示，减少动画模式不改变结果 |
| 触控与键盘 | 同一个 Action 入口；只在适用棋盘操作时阻止页面默认滚动 |

本节没有宣称任何屏幕宽度、帧率或浏览器已经通过验收。最低设备、目标时延及部署环境由 D15 固化，再执行 M8-01。主题色和动效时长沿用源基准，实际对比度和手感需测试。
