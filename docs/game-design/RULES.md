# 棋盘与通用规则 RULES

> 文档版次：0.1.0-docs.1 · 2026-11-25 · Phase 0 文档交付；游戏尚未实现。
> 来源：[输入基准](../reference/SOURCE-BASELINE.md)；对应章节 / 说明：3。
> 效力：仅 PRD 明列项为用户已确认；其余沿用设计基准。本文新增接口细化、测试设计、任务拆分属于交付建议；所有初始数值待模拟与试玩验证。
> 待决议建议没有生效；受影响规则落地前须关闭对应 [D 项](../development/OPEN-DECISIONS.md)（验证型门按登记说明执行）。

### 3.1 棋盘

- 4×4；普通方块数值为 2 的正整数次幂；空格与普通方块、障碍、临时锁定状态必须可区分。
- 方向上/下/左/右；向指定方向压缩，相邻相同数字合并为两倍数值；同一方块每次有效滑动最多参与一次合并，不允许刚产生的方块在同一步再次合并。
- 合并基础分数为新方块数值之和；合并数量按方块对计数。
- 有效滑动改变棋盘布局或产生合并，增加一次有效移动，并生成一个新普通方块（通常 2 为 90%、4 为 10%，可被规则修饰）。无效滑动不增加步数，不生成方块，不消耗 RNG，不推进 Boss 或词缀计数。
- 进入关卡时先放障碍，再生成两个普通方块，随后添加技能和词缀额外方块。
- 不设置现实时间限制；步数是特殊关卡目标或机制时钟，不是全局倒计时。
- 普通主动技能不增加移动数、不生成普通随机方块、不产生 EP、合并分数或 Boss 伤害；若达到数字目标，仍可通关。矩阵重构使用确定性随机流。
- 方块 ID 独立、确定性生成；UI 依据事件和 ID 实现位移/合并动画，而非自己计算规则。

基础移动测试（不含随机生成）：

| 输入（向左） | 输出 | 基础分数 |
|---|---|---:|
| [2,2,2,2] | [4,4,0,0] | 8 |
| [2,2,4,0] | [4,4,0,0] | 4 |
| [4,0,4,4] | [8,4,0,0] | 8 |
| [2,0,2,2] | [4,2,0,0] | 4 |
| [4,2,0,0] | [4,2,0,0] | 0（无效） |

### 3.2 障碍与锁定

数据污染障碍固定在一个格子，不可移动、合并、被普通技能选中；将行列划分为独立移动区域，方块不能穿越它。以 X 表示障碍：

- [0,4,X,4] 向左 → [4,0,X,4]
- [X,2,2,0] 向左 → [X,4,0,0]
- [2,2,X,4] 向左 → [4,0,X,4]

Boss 的临时锁定是带原有数值的普通方块状态，不是永久障碍；锁定期间移动/合并和普通主动技能均不可作用，解锁后还原原值。移动时同样分割区域。

### 3.3 结算与终局

原讨论中普通关卡建议「移动→合并/分数/EP→随机生成→通关检查→关卡特殊机制→救场→失败→存档」；Boss 明确规定「移动→合并/分数/EP→伤害→若 HP 归零则胜利并取消后续生成/攻击→否则生成→更新封锁→Boss 行动→救场/失败→存档」。这两个流程保留为原设计基准，2026-11-26 已确认普通关在生成后检查目标。

棋盘填满不等于失败：必须检查是否仍有合法滑动。无合法滑动且不存在有效救场能力才判定失败；自动救场和合法主动救场优先于失败。胜利优先于同一操作触发的环境惩罚/Boss 攻击。终局状态禁止游戏输入。

一次接受的 Action 原子提交完整状态及事件；不持久化中间结算；动画不参与游戏规则。UI 取消选择、能量不足、非法目标、无效滑动不改变引擎状态。

## 操作契约与冲突统一口径

| 操作 / 情况 | 基准行为 | 未定边界 |
|---|---|---|
| 有效 MOVE | 改变棋盘、一次有效步、普通合并计分/EP、通常生成一个普通方块 | 普通关判胜时点 D02、完整阶段顺序 D03 |
| 无效 MOVE | 拒绝；棋盘、分数、EP、计数器、ID 与四 RNG 均不变 | 无 |
| 普通主动技能 | 不增加步数、不生成普通随机方块、不直接产生分数/EP/伤害 | 无效交换/重排 D07、D13 |
| 状态回滚 | 撤销上一有效 MOVE 的完整结算，再支付成本；不跨奖励/关卡/其他主动技能 | 整轮一次性救场标志 D10；细则以 SAVE-REPLAY 为准 |
| 胜利与攻击同时发生 | 胜利优先，不执行后续环境惩罚；Boss 致死不再生成或攻击 | 普通关保留生成（D02 已确认） |
| 无合法 MOVE | 先考虑救场，不能只凭满盘判败 | 自动/手动顺序及可救判定 D08；锁定死局 D09 |

「不直接计分」不禁止技能变更方块后在未来普通合并中得分。「状态回滚」会恢复历史分数/EP/步数，不适用普通技能不变更这些历史字段的简化理解。

D02 已确认。全部初始化方块放好后立即检查目标；普通关有效滑动在常规生成后检查目标；Boss 致死立即结束。

## 引擎不变量（基准的验收表达）

- 棋盘为 4×4；同一格只有一个 Cell；活跃方块 ID 唯一；数值为有效的 2 的正整数次幂，安全上限由 D11 决定。
- 无障碍/锁定跨越，无新合成方块同一步二次合并；纯移动合并步骤在不生成/删除时保持数值总和。
- 当前 EP 在 0 与有效上限之间；拒绝操作不改变完整逻辑状态、不记成功日志、不写存档。
- 逻辑结果不依赖动画时长、真实时间、浏览器或无种子随机数；输入对象不可原地修改。
- 每个成功 Action 只提交一次完整事务；胜利/失败态拒绝后续游戏操作。
- 规则模块不得将技能生成、重排、回滚误识别为普通合并，防止重复收益与递归触发。
