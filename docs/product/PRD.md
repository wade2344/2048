### 1.1 已确认的产品决策

| 决策项 | 用户选择 |
|---|---|
| 项目目标 | practice：AI Coding 工程实战，不以商业化为首要目标 |
| 游戏类型 | 2048 + Roguelike |
| 平台 | H5，移动端优先，兼容桌面键盘 |
| 冒险形式 | B：关卡闯关，每关重新初始化棋盘，继承技能 |
| 成长形式 | A：通关成长，关卡内不升级 |
| 主题 | 数字科技：深空、数字能量、极简科幻 |
| 技能资源 | B：共享 EP 能量池 |
| 关卡随机性 | B：固定目标 + 随机词缀 |
| Boss | A：伤害输出型，后续逐步演进至 D：多阶段攻防型 |
| 数据能力 | B：存档 + 随机种子 + 操作回放 |
| 平衡方法 | C：自动化模拟 + 人工试玩 |
| 工程架构 | B：pnpm Monorepo 多包架构，轻量规则扩展机制 |
| 交付流程 | Issue → AI Agent → Coding → 测试/CI → Draft PR → 人工验收与合并 |

暂定项目名：**2048: INFINITE / 2048：无限进化**。核心受众是熟悉或愿意学习 2048 的玩家；核心体验是通过不同技能组合和环境规则产生不同的关卡策略。作为工程实践项目，重点考察模块边界、确定性引擎、自动化回归、CI 和持续交付。

### 1.2 首版范围（设计基准）

- 4×4 棋盘；六个线性冒险关卡；四种流派共十二个技能、十二个环境词缀、一个最终 Boss。
- 前五关通关后从未拥有技能中随机三选一；Boss 通关直接结算。
- 键盘和触屏控制、位移动画、技能目标交互、关卡准备与状态预告。
- 单槽自动存档、种子与 RNG 状态、操作日志、只读回放、JSON 导入/导出及 Bug 复现能力。
- CLI 数值模拟器，Random、Greedy、Strategic 三种 Bot；数值报告与人工试玩验收。
- 无需后端、账号、联网排行、广告、付费、多人、商店、分支地图、永久天赋或角色养成。首版不采用 Canvas/WebGL，不开发通用 Agent 框架。
- 单局体验目标 15–25 分钟，属于待验证目标，不是承诺。

### 1.3 版本路线

| 版本 | 交付内容 |
|---|---|
| V0.1 | 经典 2048 可玩原型、触屏、基础动画 |
| V0.2 | 关卡循环、通关奖励、共享 EP |
| V0.3 | 十二技能、十二词缀、ZERO Boss、六关闭环 |
| V0.4 | 存档回放、模拟器、数值对照 |
| V1.0 | 体验优化、完整验收、H5 发布 |
| V1.x | 增加技能、词缀、Boss 攻击与阶段、Expectimax、开发者面板 |
| V2.0 | 多阶段攻防 Boss：玩家 HP、护盾、弱点、阶段转换 |
