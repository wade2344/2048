# 里程碑与实施路线 ROADMAP

> 文档版次：0.1.0-docs.1 · 2026-11-25 · Phase 0 文档交付；游戏尚未实现。
> 来源：[输入基准](../reference/SOURCE-BASELINE.md)；对应章节 / 说明：1.3、16–17。
> 效力：仅 PRD 明列项为用户已确认；其余沿用设计基准。本文新增接口细化、测试设计、任务拆分属于交付建议；所有初始数值待模拟与试玩验证。
> 待决议建议没有生效；受影响规则落地前须关闭对应 [D 项](OPEN-DECISIONS.md)（验证型门按登记说明执行）。

## Phase 与 Milestone 的对应

Phase 0：本次文档拆分与验收，不实现代码；覆盖 M0-02/03 的文档草案，但未完成真实仓库入库、平台配置或人工接受。

Phase 1：经后续明确授权后初始化工程与 CI（M0-01/04 等）。Phase 2：使用成熟 Agent 跑通一个真实小 Issue→Draft PR→人工验收闭环，再持续按 M1–M8 实现。Phase 2 是工作流阶段，不等于 M2 游戏关卡里程碑。

## 里程碑入口、增量与出口

| 里程碑 | 入口 / 任务数 | 可演示增量 | 必须有的出口证据 | 主要未决门 |
|---|---|---|---|---|
| M0 工程基线 | Phase 0 审阅；4 工作包 | 两应用共享契约、规则文档、模板和真实基础 CI | 锁定安装/构建、依赖约束、失败 PR 被阻止 | D15 环境/版本 |
| M1 经典原型 | M0 可运行；5 工作包 | 可操作经典 2048、确定性、动画 | 经典数组、四方向、触屏/键盘、同 Seed 轨迹 | D01/02/11/16/18，D15 输入 |
| M2 闯关成长 | M1；4 工作包 | 前五关目标、奖励和准备/结算 | 状态机、五次三选一、重置继承；Boss 占位明确 | D02/17/18/19 |
| M3 技能构筑 | M2 与移动基础；5 工作包+12 子卡 | EP、12 技能、最小回滚 | 单技能用例、资源/救场组合、最小日志与 undo | D03/04/05/08/10/13 等 |
| M4 环境 | M3；4 工作包+12 子卡；障碍可提前 | 12 词缀、兼容抽取、真实有效数值 | 白名单/空池、周期事件、组合回归 | D03/05/06/07/17 |
| M5 ZERO 与完整冒险 | M3/M4；4 工作包 | 六关真实可通关，Boss 伤害/封锁 | 固定 Seed 胜败轨迹、击杀优先、封锁保护 | D08/09/19 |
| M6 数据能力 | M5；4 工作包 | 单槽恢复、完整回放 UI、Bug 包 | 稳定 phase 恢复、版本/损坏拒绝、回放隔离 | D10/11/12/18/19 |
| M7 数值系统 | 真实六关引擎与日志；5 工作包 | 三 Bot、CLI/JSON、A/B | 可观察隔离、报告分母、复现异常与对照 | D14 验证采纳、D19 口径 |
| M8 V1.0 | M6/M7；4 工作包 | 兼容、试玩、授权部署与发布 | 真实设备/性能/试玩证据、部署访问和回滚、人工验收 | D14/15 |

M1-03 提前建立最小成功日志契约，M3-04-S12 建立回滚快照；M6 不从零补这两项，主要完成持久化、完整播放器与跨机制回归。M4-02 仅依赖移动基础，可在技能之前独立开发，但不会改变整体版本范围。

## 产品版本与验收范围

| 产品版本 | 工作包覆盖建议 | 限制 |
|---|---|---|
| V0.1 | M0–M1 | 经典可玩，不声称完整 Roguelike |
| V0.2 | M2 + M3-01 | 关卡/奖励/共享 EP，不声称 12 技能全可用 |
| V0.3 | M3–M5 | 12/12/6 与 ZERO，完整数据 UI 尚未完成 |
| V0.4 | M6–M7 | 存档回放、三 Bot 与数值报告 |
| V1.0 | M8 | 人工验收后的 H5 发布 |
| V1.x / V2.0 | 独立未来 Issue | Boss A→D、Expectimax、开发者面板，不混入首版 |

本表是交付顺序建议，不承诺日历工期。实际顺序以 [任务 DAG](BACKLOG.md) 为准；任何开发开始前检查范围内 D 项，不能以阶段名称宣称依赖已完成。
