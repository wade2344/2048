## 背景

Bug 重现与 UI/模拟一致性依赖同输入同输出。

## 保留的决策

确定性纯 TS 引擎 + 同步 dispatch：便于复现、测试、回放和模拟。

## 替代方案与取舍（源基准）

UI 内直接逻辑或非确定性事件总线更快起步，但难重放与隔离。要求固定顺序和不可变状态。

## 影响与实施约束

分规格唯一入口：[相关规格](../architecture/ENGINE.md)。本 ADR 不添加源文件之外的功能；数值不是实测结论。相关待决议：D03、D11、D16，详见 [开放决议](../development/OPEN-DECISIONS.md)。依赖未关闭前只能实施不受影响部分。
