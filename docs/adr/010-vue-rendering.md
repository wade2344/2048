## 背景

4×4 数字棋盘需要可读、可测、响应式的轻量呈现。

## 保留的决策

CSS/WAAPI 渲染 + Vue H5。

## 替代方案与取舍（源基准）

Canvas/WebGL 更适合复杂特效但非首版必要；保持数字可读、可测试、易适配。
